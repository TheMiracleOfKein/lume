# Lume user guide

How to use Lume, from the first launch to every setting. Names in **bold** are the words you see on the screen (English). If something here doesn't match your app, check **Settings → About and licenses** for your version and read the [release notes](../releases/).

## Start here

- [Getting started](getting-started.md): pick a build (full, manga or ranobe), install, the Manga and Ranobe modes, and the Home screen.
- [Browsing and sources](sources.md): the catalog, global search, built-in sources, JSON packs, your own servers (OPDS, Komga, Kavita) and local files.

## Reading

- [Title screen](title-screen.md): chapters, one title from several sources, similar titles, trackers on a title.
- [Reading manga and comics](manga-reader.md): webtoon and paged modes, zoom, guided panel view, cropping and spreads, page bookmarks.
- [Reading novels (Ranobe mode)](novels.md): RanobeLib, Royal Road, Scribble Hub, NovelFull, NOVGO, EPUB and TXT books, the text reader, read aloud, name lookup and codex, novel trackers.
- [Translation and AI](translation-and-ai.md): translate chapters (Google, DeepL, AI with your key, offline on the phone), glossary, AI story notes, recap and codex summaries.

## Your library

- [Library](library.md): categories, updates, statistics, reading lists.
- [Downloads](downloads.md): the queue, storage, automatic downloads, sending chapters to a nearby phone.
- [Sync and backups](sync-and-backups.md): sync through a folder or WebDAV, backups, importing from Mihon, Tachiyomi, Kotatsu and MangaLib.
- [Trackers](trackers.md): AniList, Shikimori, MyAnimeList, Kitsu and MangaUpdates.

## Help

- [Privacy and security](privacy.md): incognito, app lock, encrypted sign-ins.
- [Troubleshooting and FAQ](troubleshooting.md): crash log, site checks, region blocks, error messages.
- [Settings reference](settings.md): every setting with its default.

## What works in which mode

| Feature | Manga mode | Ranobe mode |
| --- | --- | --- |
| Built-in sources | 13 sites + local files | RanobeLib, Royal Road, Scribble Hub, NovelFull, NOVGO + EPUB/TXT |
| JSON packs, own servers | Yes | No |
| Finding a title on other sources when you add it, similar titles | Yes | No |
| Downloads, nearby sending | Yes | Yes |
| Read aloud, translation, name lookup, codex | No | Yes |
| Trackers | AniList, Shikimori, MyAnimeList, Kitsu, MangaUpdates | AniList, Shikimori, MyAnimeList |
| Library, updates, sync, backups, statistics | Yes | Yes |
