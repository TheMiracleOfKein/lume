## Failures

No serious problems found (no crash, no broken navigation, no data loss, no layout break).

## Minor

### M1. Zero-chapter title shows "Chapter list (0)" without explanation (B8)
- Repro: Menu → Source: ReManga → Catalog or search → "Поднятие уровня в одиночку" (Solo Leveling, status Лицензировано).
- Current: "Chapter list (0)" and a disabled "Read" button, with no reason shown.
- Expected (suggestion): a short note such as "No free chapters on this source", or a count that says paid chapters are hidden.
- Pre-existing: the `is_paid` filter is the same in v0.7.15 (RemangaEngine.kt, the `if (paid) continue` line).

### M2. Reader error text does not say why the page failed (B7)
- Repro: ReManga → "Поднятие уровня в одиночку: Рагнарёк" → Chapter list → Vol. 1 Ch. 1.
- Current: "Page failed to load" and Retry. The cause here is a 403 on the image host (geo-block).
- Expected (suggestion): the region message used for MangaBuff, when the image host returns 403 for a region. Lower priority: this happens only on this network.

### M3. Stray focus on Quick search when going to Menu (not reproduced)
- Once, a tap on the Menu tab landed on the Home Quick search field and opened the keyboard. Back then dismissed the keyboard, and the next back left Lume to the launcher (normal back-on-root behaviour). Lume relaunched into the same process.
- Not reproduced in later attempts. Treat as an observation only.
