# Lume v1.13.0

Source addresses without an update. When a site moves its API, Lume can learn the new address from a small list on GitHub instead of waiting for a new version. This is what v1.12.1 needed: the Lib sites changed their address and the app had it built in.

## New

- **Update source addresses** (Settings → Network, on by default). Lume reads a short file of addresses (`hosts.json` in the project) at start, at most every 6 hours, and again soon after a site did not answer. It keeps the last copy, so it also works offline. Only addresses are fetched: no code, no headers, nothing about your account. Turn it off and Lume uses the addresses inside the app.
- **Another address when one fails.** If a site's address does not resolve or cannot be reached, Lume tries the next one on the list (for the Lib sites, `api.lib.social` and `api.mangalib.me`) and uses the one that worked for the rest of the session.

## Safety

- Every address must be `https`.
- The Lib sites, where the sign-in goes to the API, can only move between the known Lib domains. Moving them to a brand-new domain still needs an update.
- Your own servers (OPDS, Komga, Kavita) and local sources never take an address from the list.
