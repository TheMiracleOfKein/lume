# Lume v0.1.0

The first public release of Lume, an Android reader for manga, manhwa and webtoons.

## What's included

- Library, home feed, catalogue, search, downloads and an offline cache.
- Webtoon (vertical) and paged reader.
- Built-in sources, plus JSON packs for supported site families ([docs/ENGINES.md](../ENGINES.md)).
- Optional tracker: Shikimori.
- Backup and restore.
- English and Russian.

## Requirements

Android 8.0 (API 26) or newer.

## Installing

Install the APK from the release. If Android blocks the install, allow installs from your browser or file manager.

What came next is in [v0.2.0](v0.2.0.md) and the [roadmap](../ROADMAP.md).
