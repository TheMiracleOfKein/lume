# Lume v1.5.0

Novels on your trackers, filters for the English novel sites, and readable error messages.

## New

- **Novel lists on trackers**: AniList, MyAnimeList and Shikimori now handle novels (light novels / ranobe), not only manga.
  - The Trackers button on a novel searches the tracker's novels, and adding a novel to the library links it on its own when the name matches exactly.
  - Chapters finished in the text reader update the chapter count on every linked tracker.
  - Settings → Trackers → import brings in your "Reading" list for the mode you're in: novels in Ranobe mode, manga in Manga mode. Titles are looked up only on sources of that mode. Shikimori can now import its list too.
  - Manga searches on AniList and MyAnimeList no longer offer novels.
- **Royal Road and Scribble Hub filters** in the catalogue's filter sheet:
  - Royal Road: sort order (ascending or descending), status, type (original or fan fiction), and genres, content warnings and tags to include or exclude.
  - Scribble Hub: sort order, status, genres and tags to include or exclude, matching any or all of them.
- **Save for this title** in the text reader's settings: text size, theme and page mode can be kept for one novel, like the manga reader already does. Font, margins and spacing stay shared. "Reset to defaults" in the reader also drops the title's saved settings.

## Fixed

- The readers and the title screen show a readable message when something goes wrong (no connection, the site took too long, the site refused, the chapter couldn't be read), never an internal name like "z73". The full text is still kept in the error log for "Share log".

## Updating

Install it over v1.4.2 as usual. Your library, progress, bookmarks, downloads and sign-ins are kept. The database moves from version 16 to 17 (three new per-title text reader columns), automatically on the first start. Backups from older versions still load.

## For developers

- Trackers: `search`, `link` and `fetchReadingList` serve `MediaKind.Novel` on AniList (`format_in: [NOVEL]`), MyAnimeList (`media_type` `light_novel`/`novel`) and Shikimori (`/api/ranobe`, list from `manga_rates` split by `manga.kind`). Progress calls stay kind-agnostic. `TrackerSync.autoLink` and `TrackerListImport.start` take the kind. No change to tracker links in the database.
- `Throwable.userMessage()` in `core/data` (`ErrorMessages.kt`) maps errors to localized text and replaces blank or obfuscated messages; readers also record the error in `ErrorLog`.
- The saved-page parser tests of `feature/novel` and `feature/comics` moved to `src/sharedTest` and also run on Android (`:feature:novel:connectedDebugAndroidTest`, `:feature:comics:connectedDebugAndroidTest`), with tests that build every engine so a pattern that only fails on Android's regex engine is caught. The emulator workflow runs them.
- `TitlePrefsEntity` gains `novelFontSize`, `novelTheme` and `novelPaged` (`MIGRATION_16_17`), carried in backups (optional fields, same format version) and sync.
- `RoyalRoadEngine.searchPath` and `ScribbleHubEngine.searchPath` build the filtered search URLs; Scribble Hub tags are read from its series finder form.
