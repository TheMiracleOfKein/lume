# Lume v1.1.1

Settings now follow the reading mode, and a tap on a similar title looks for it on the source you are reading.

## Changed

- **Settings per mode.** In the Ranobe mode, Settings shows what applies to books:
  - Settings → Reader holds the text reader's defaults: text size, line spacing, margins, paragraph spacing, font, justified text and theme, with a preview. The reader's own settings panel changes the same values.
  - Downloads, Trackers, Similar titles and "Find other sources" are hidden, since they work for manga only for now. "Import books…" shows only in the Ranobe mode.
  - Appearance (with the app language), Library and updates, Sources, Sync, Backup, Privacy and Network are shared by both modes.
  - The settings search finds only the settings of the current mode, and the main Settings page says which mode it shows.
- **Similar titles.** A tap on a recommended title now searches the source of the title you have open:
  - one result with exactly that name: it opens;
  - other results: that source's search opens with them;
  - nothing found: Lume offers to search all your sources.
- **18+ sources** are now left out of global search unless you turn them on in Settings → Sources. If you turned the switch on yourself, it stays on.

## Updating

Install it over v1.1.0 as usual. Your library, progress, settings and sign-ins are kept. No database change.

## For developers

- `SettingsPage.modes` and `SettingInfo.modes` say which modes show a section or a setting; `SettingItem` leaves out the rows that don't apply to `LocalSettingsMode`.
- Content modules add their reader defaults to Settings → Reader with `ShellGraph.readerSettings(kind)`; `:feature:novel` registers `NovelReaderDefaults`, which uses the same controls as the reader's sheet (`NovelReaderSettingsControls`).
- `pickSearchResult` (`TitleMatching.kt`) decides between opening a result, showing the search and finding nothing; JVM tests cover it. `Routes.browse` takes a `query`, and the catalogue opens on that search.
- The device check is in [v1.1.1-check.md](checks/v1.1.1-check.md).
