# Lume v0.9.13

A quality release on the way to 1.0: a genre filter in the library, a QR code for nearby sending, a MangaLib bookmark import that keeps going when Android closes the app, easier-to-read colours and large fonts, a chapter list that no longer jumps, and a user guide.

## New

- **Genre filter in the library.** Open the library options, **Filter** tab, and tick one or more genres. Only titles with every ticked genre are shown. It works together with the other filters and is remembered. Genres are saved per title: titles you have opened before show theirs right away, and the rest fill in when you open them or when the library updates.
- **QR code for nearby sending.** The send screen shows a QR code. On the receiving phone, tap **Scan QR code** and point the camera at it; it connects as if you had typed the address. The six-digit pairing code is still shown on both screens and checked as before. The camera is only used to read the code, and the button is hidden on phones without a camera.
- **User guide.** [USER_GUIDE.md](../USER_GUIDE.md) explains reading, sources and packs, the library, downloads, sync, backups, trackers and troubleshooting, with a reference of every setting.

## Improved

- **MangaLib bookmark import** now runs as background work with a progress notification, so it finishes even if Android closes the app. Running it again never adds a title twice.
- **Readable colours.** Secondary and hint text, error text, field borders, the selected chip and the amber accent used as text now meet the WCAG AA contrast level in the light, dark and AMOLED themes.
- **Large fonts.** Top bars, the reader bars and the search field grow with the system font size instead of cutting text; the sync passphrase and tracker sign-in dialogs scroll; navigation labels end with "…" instead of being cut.

## Fixed

- **Chapter list jump.** Selecting a chapter no longer pushes the list up: the selection bar now slides in over the list, and the last chapters can still be scrolled above it.

## Updating

Install it over v0.9.12 as usual. Your library, progress, bookmarks, downloads and sign-ins are kept. The database moves from version 14 to 15 (a genre list per library title, empty at first). Backups from every earlier version still restore; new backups also carry the genres.

## Privacy

Lume now asks for the **camera** permission, only when you tap **Scan QR code**, after explaining why. Nothing from the camera is saved or sent. Denying it only turns off scanning; typing the address still works.

## For developers

- Database 14 → 15: `bookmarks.genresJson TEXT NOT NULL DEFAULT '[]'` (`MIGRATION_14_15`). Genres are written by `TitleRepository` on every fetch from the site, backfilled by `LibraryUpdateWorker` (up to 25 titles per run) and read from the details cache as a fallback. Filter logic in `domain/LibraryGenres.kt`; the selection is the `library_genre_filter` preference. Backups: optional `genresJson` on bookmarks ([BACKUP_FORMAT.md](../BACKUP_FORMAT.md)).
- `LibBookmarkImportWorker`: unique work `lib_bookmark_import:<sourceId>` (KEEP), expedited, foreground `dataSync`, notification channel `bookmark_import`. `LibBookmarkImport` keeps the `status` flow the Sources card reads.
- Nearby QR: `data/nearby/NearbyQr.kt`, `lume-nearby://host:port?name=…` (IPv6 in brackets). ZXing core 3.5.4 and zxing-android-embedded 4.3.0, both Apache-2.0, no Play services. About 170 KB more in the release APK.
- Chapter list: `ChapterSelectionBar` is an overlay in the Scaffold content with a fixed bottom content padding, not the `bottomBar`.
- Theme: new colour values in `AppColors.kt`, accent as foreground through `accentText`; `ThemeContrastTest` checks the pairs. Notes in [ACCESSIBILITY.md](../ACCESSIBILITY.md).
- Tests: `ReaderViewModelTest` and `LibraryViewModelTest` (Robolectric, real `AppContainer`, in-memory data); the Room `MigrationTest` now runs on Windows JVM too (full-path open helper name). Screenshot tests with Roborazzi for Home, Library, Title, Chapters, Settings and the reader bars in light, dark and 200 % font (`app/src/test/screenshots`, `verifyRoborazziDebug` on CI). A new `emulator.yml` workflow runs `connectedDebugAndroidTest` (migrations and `SmokeTest`) on an API 34 emulator.
- Device check: [v0.9.13-check.md](v0.9.13-check.md).
