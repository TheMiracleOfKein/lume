# v0.9.10 device check

Debug build of `feat/trust-and-fixes` on the Pixel 6a emulator (Android 17, API 37), 2026-11-11.

The installed APK reports `Version 0.9.9 (41)`. The build was made before the version bump in `app/build.gradle.kts` (now `0.9.10`, code 42), so the version label was not checked against 0.9.10.

## Changed areas

- Crash log: `data/CrashLog.kt`, saved uncaught crashes, About → "Share log", "Clear crash log" with confirmation.
- Backup format: `"version": 5` and `"createdAt"` written at the top of backups.
- Accessibility: while the main menu is open, the screen and bottom bar leave the accessibility tree (`ui/shell/AppShell.kt`).
- Search marks: library status bar also for a title saved from another source (`ui/components/LibraryMarks.kt`, `domain/LibraryStatus.kt`, `ui/screens/SearchScreen.kt`).
- Russian strings for the crash log card.

## Problems found

1. Stale build label (low): the tested APK is `0.9.9 (41)` while `app/build.gradle.kts` says `0.9.10 (42)`. Rebuild after the version bump before the release check.
   Steps: install `app/build/outputs/apk/debug/app-debug.apk`, open menu → About. The version line reads 0.9.9.
2. None of the other checks reproduced a bug.
