# Lume 0.7.2 pre-release check

Build: debug APK of branch `feat/lib-bookmark-import` on emulator-5554 (installed versionName 0.7.1, versionCode 14, as reported by the package manager; the debug build carries the branch changes).

## Changed areas
- Sources screen: new "Import bookmarks" item in the ⋮ menu of MangaLib-family sources (MangaLib, HentaiLib, YaoiLib), shown only when signed in; spinner on the row while importing.
- `SourcesViewModel.importBookmarks`, `LibBookmarks`, `LibSocialEngine.fetchBookmarks`, `LibBookmarkImport`, EN/RU strings, `AppContainer`.

## Checked
1. Sources screen, ⋮ menus (signed out):
   - MangaLib: Browse, Pin to top, Disable, no "Import bookmarks" (checked by the previous run).
   - ReManga and Asura Scans: Browse, Pin to top only, no "Import bookmarks". Menus close with back.
2. Rotation on the Sources screen (landscape, user_rotation 1): draws the screen, no crash. Rotation restored to portrait.
3. Smoke test:
   - Home loads (Quick search, carousel, Currently reading, New releases).
   - Catalog loads (Popular list).
   - Overgeared details: Read, Chapter list, Sources, Trackers, Description, Similar titles.
   - Chapter list loads (347 chapters, Asura Scans).
   - Find on other sources lists MangaDex, MangaKatana, ReManga, Vortex Scans; MangaKatana linked as a fallback source.
   - Add to library (bookmark icon): icon turns filled; Library shows Overgeared.
   - Updates: "Update now" (refresh icon) gives "Checked 0 minutes ago".
4. Logcat: no FATAL EXCEPTION from com.lume.app. The 8 FATAL entries (15:45–15:48) are from `uiautomator dump` processes started during testing, not from Lume.

## Failed
1. Reader draws no pages (serious for reading, not a crash).
   - Repro: Home → Catalog → Overgeared → Chapter list → tap Chapter 346 (or 340). The reader shows the Asura cover card and the page strip stays black, 21/22 pages, for 35+ seconds. Tap and swipe do not change it.
   - Also fails after linking MangaKatana as a fallback source and opening chapter 346 again: the reader stays black. Full-screen mode, after "Got it", is black too.
   - No error lines from the app's process in logcat (no image or network errors logged).
   - **Follow-up, not caused by this release.** Chapter 300 (a year old, not early access) is black too. The Asura API returns its pages and `cdn.asurascans.com` serves them (HTTP 200, 1.1 MB WebP). Page 1 is 1200×800 and draws; pages 2 and on are 800×~14,500 px strips that stay black. This is the known tall-page limit ("Tall pages in pieces", planned for v0.8), made worse by the emulator's software GPU (swiftshader caps texture size). `git diff v0.7.1..HEAD` touches no reader, image or network code, so v0.7.1 behaves the same. Not a blocker for v0.7.2; worth checking on a real phone and moving "Tall pages in pieces" earlier if phones show it too.

## Not checked
- The signed-in "Import bookmarks" itself and its spinner: needs an account; the user did not provide one, and no sign-in was attempted.
- MangaLib API: region-blocked from the build machine.
- Language switch, release APK, signing, the emulator's own Android-MCP tools (not available in this session; adb used throughout).

## Notes
- Element positions came from screenshots (uiautomator dump does not work in this session); taps were checked by screenshot.
- Test side effects on the emulator: Overgeared is in the library, and MangaKatana is linked to it. The emulator is started with -wipe-data, so nothing persists. The emulator was left running.
