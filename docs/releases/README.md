# Release notes

- [checks/](checks/): the pre-release device check report of a version (`vX.Y.Z-check.md`): what changed, what was checked on the emulator, what passed and what wasn't checked.
- [ROADMAP_ARCHIVE.md](ROADMAP_ARCHIVE.md): the detailed roadmap up to v1.13.0, frozen. The current plans are in [ROADMAP.md](../ROADMAP.md).
