# Lume v0.7.9

The last back animation is gone: going back no longer shrinks or moves the screen anywhere.

## Fixed

- **No back animation anywhere.** v0.7.8 made going back between screens instant, but Android's own back animations were still on. While you held the back gesture, the app could shrink into a card before closing, a login screen could slide away, and bottom sheets could shrink under your finger. All of them are off now. During the gesture the screen stays as it is, apart from the small system arrow at the edge, and back happens when you let go. The back button and the arrow work as before.

## Updating

Install it over v0.7.8 as usual. Your library, progress, bookmarks and downloads are kept. No database changes.

## For developers

- `AndroidManifest.xml`: `android:enableOnBackInvokedCallback="false"` on the application (was `true`). This turns off the system predictive-back animations (back-to-home, cross-activity) and gesture progress for Compose handlers (Material sheets, NavHost). Checked on API 37 with targetSdk 37: the opt-out is honoured, and the window's back callback is registered with `mIsAnimationCallback=false`. `BackHandler`s still receive the completed back.
