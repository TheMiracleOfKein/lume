# Lume v1.5.4

Tabs that follow your finger.

## Changed

- **Swiping between tabs feels immediate.** In the Catalog and in Search, the line under the tabs now slides along with your finger. The tab's name lights up as soon as the next page is the nearer one, not after the swipe has come to rest. In the Library, the category chip changes the same way. The pages next to the one you see are prepared ahead, so they're already there when they slide in, instead of filling in a moment later.
- **The Catalog's search bar stays on the Library tab.** It used to disappear there, which made the tabs jump up and down when you swiped to Library and back.

## Updating

Install it over v1.5.3 as usual. Your library, progress, bookmarks, downloads, sign-ins and tracker links are kept. No database change.

## For developers

- `SwipeTabRow` (`core/ui`, `SwipeTabs.kt`) replaces `SegmentTab`: one underline for the row, placed at layout time from the pager's live position (`currentPage + currentPageOffsetFraction`) while it moves, and on the selected tab at rest. `rememberSwipeTabState` hoists the `PagerState` the row and `SwipeTabPager` share.
- `SwipeTabPager` reports a swipe when `currentPage` changes (not when the pager settles), slides to a tapped tab with `Motion.medium()`, jumps without a slide when it comes back on screen, and keeps one page on each side composed (`beyondViewportPageCount = 1`).
- Released without the emulator gate and the release smoke test, on the user's request.
