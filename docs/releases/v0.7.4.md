# Lume v0.7.4

MangaLib bookmark import now brings your read progress along.

## New

- **Read progress from the site.** For every bookmark with a last-read chapter on MangaLib, HentaiLib or YaoiLib, Import bookmarks marks that chapter and every earlier one read, for every translation team. A title you haven't opened in Lume yet continues from that chapter.
- Nothing is taken away: chapters you already marked read and your current spot in a title stay as they are.
- When it's done, the message also says how many titles got their progress. If some titles' chapters couldn't be loaded, or the site's chapter isn't in the list any more, a second message says how many.

## Updating

Install it over v0.7.3 as usual. Your library, progress, bookmarks and downloads are kept. No database changes.

To bring progress for titles you already imported, run ⋮ → Import bookmarks again. It doesn't make duplicates.

## Known limits

- The import loads a chapter list for each read title, so a big library takes a few minutes. The site limits how fast it can be asked.
- Titles bookmarked on another Lib site are left out: import them from that site's source.
- The import needs a sign-in. A site that blocks your region blocks the import too.

## For developers

- `parseLibBookmarksPage` reads each entry's `item` (`model: "chapter"`, `volume`, `number`, `branch_id`) into `LibBookmark.lastRead` (`LibReadChapter`), with `updated_at` as the time.
- `LibBookmarkImport` takes `LibraryChapters`. After the bookmark transaction it loads `getChapters` for read titles (3 in parallel, one retry after 1.5 s), finds the chapter with `libChaptersReadUpTo` (volume + number; number alone only when it's unique), syncs `library_chapters`, adds `chapter_read` rows and a `reading_progress` row when there is none.
- New cases in `LibBookmarksTest`.
