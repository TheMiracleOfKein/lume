# v1.5.6 device check

Emulator (API 34, 720×1600), full debug build, Asura Scans "Overgeared", reader in Right to left mode with guided panel view on and panel order Right to left.

## Background

A follow-up check of v1.5.5 found that a page could appear already zoomed into a panel: going back onto the previous page showed its last panel, and a seekbar jump showed a page zoomed on a panel without a tap. The zoom state is saved with the page and outlives the guided step. v1.5.6 resets the zoom of a page that arrives without a step.

The same v1.5.5 follow-up check also passed: right to left stepping (left third forward), stepping back through panels, a swipe turning the page and the next page starting at panel 1, spreads "Always" turning spreads without panel steps, webtoon mode hiding the guided toggle and panel order, no crash in landscape.

## Checked

| Check | Result |
|---|---|
| Going back a page from a whole page: previous page arrives whole | Pass (pages 5 → 4 → 3, all whole) |
| Zoom into a panel, jump with the seekbar away and back: both arrivals whole | Pass |
| Normal stepping from a whole page: panel 1 zoomed, rest dimmed | Pass |
| Rotation to landscape and back: page whole, no crash | Pass |
| `FATAL EXCEPTION` in logcat | None |

## Not checked

- The exact sequence "step to the last panel, turn the page, come back" (covered by the same code path as going back a page).
- A full swipe to the next page and back in guided mode (the swipe snapped back).
- Panel order switching visually: the test chapter has no side-by-side panels.
- E-ink without animation; split double pages (no wide page in the chapter).
