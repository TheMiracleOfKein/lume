Build: debug APK, full flavor (`app-full-debug.apk`), branch `feat/translated-novel-sites`, installed on the `Lume_Light` emulator (API 34). Wi-Fi off, mobile data on, so network names resolve.

Driven through mobile-mcp (taps, element lists, screenshots). adb was used only for install, logcat and the link-handling check. No sign-in to any site or tracker.

## Changed areas

- New engine `NovelFullEngine` (feature/novel) serving two English sources: NovelFull and NOVGO. Manifests `novelfull.json` and `novgo.json`; registered in `SourceEngines` and `NovelModule`.
- Link hosts for both sites added to the full and ranobe manifests.
- Everything else since v1.13.0 is documentation.

## Failed

No serious failures found (no crash, no broken navigation, no data loss, no layout break).

## Minor findings

1. **Link opens in the browser, not Lume (not a crash).** `mobile_open_url` and an `am start VIEW` intent for `https://novelfull.com/overlord-ln/chapter-1.html` both opened Chrome (first-run screen), not Lume. `cmd package query-activities` lists Lume's `MainActivity` as a candidate for the host, but Chrome was chosen with no chooser. Repro: open the URL on the emulator. Likely the browser wins for this host on this device, but worth confirming on a device with Lume as the default handler.
2. **Chapter list order is newest first by default** for both NovelFull and NOVGO. The spec expects reading order; the Sort control gives it. Decide whether the default should match the other sources.
3. **Unexpected "Found for you" sheet.** Opening the Overlord (LN) chapter list showed a "Sources" sheet suggesting NOVGO "Overlord (LN)" with "Not now", "Link" and "Find on other sources". Dismissing it works. Check that the suggestion is meant to appear on this open.
4. **Royal Road requires a Cloudflare check** (shown as "Asked for a site check ... open a title to pass it"). Expected behaviour per the roadmap. The check page shows a "Verify you are human" checkbox; I did not click it, so the Royal Road reader regression was not completed (see below).
5. **Logcat noise (not a crash).** About 10 `OpenGLRenderer: Unable to match the desired swap behavior` and about 11 `FrameTracker: force finish cuj, time out` (IME insets animation) lines from the app process. Likely emulator rendering and keyboard animation; not seen as user-facing.

## Not checked

- Royal Road reader regression (step 5): blocked by the Cloudflare verification page. Royal Road titles do show on Home and in the source list.
- Overlord (LN) chapter 1 end-of-chapter text: only the start and part of the middle were read; the reader was seeked to about 10%, not read to the end. NOVGO Prologue was read to its end.
- Exact chapter counts beyond the list badges (137 and 980) and the chapter list end for NovelFull (checked as "Epilogue" last, not counted).
- Manga-mode reading, Settings and other screens unrelated to the changes.
- Release build (only the debug full flavor was installed; manga and ranobe APKs not installed).
- Network-level checks outside the emulator.
