## Findings

### F1: best matches re-sorted above the visible part of the list (fixed)
- Steps: Search → All sources → "поднятие уровня в одиночку" → wait until every source has answered.
- Seen: Asura Scans stayed the top visible row; ReManga and MangaLib (exact Russian titles) were re-sorted to the top but sat above the screen, so they looked missing until the list was pulled down.
- Cause: a lazy list keeps the row that was first in view when items move, so the re-sort pushed the new first rows above the viewport.
- Fix: when the list is at its top as the re-sort lands, it stays at the top (`SearchScreen` requests item 0). A list already scrolled down is left where it is.
- Re-check on the emulator: after the search ends, ReManga (3 results) and MangaLib (2 results) are the first visible rows without scrolling. No `FATAL EXCEPTION`.

### F2: Novel-reader bar transition not captured (not a bug, test limit)
- The no-jump check covers settled states only (see above).
