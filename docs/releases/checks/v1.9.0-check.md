## Failures

**1. Crash on the Cloudflare check (serious: crash)**
- Steps to reproduce:
  1. Clear cookies (Settings → Network and storage → Clear cookies), or start with no Royal Road session.
  2. Open Catalog with the Royal Road source. The "Cloudflare check" sheet appears with a web view.
  3. Tick "Verify you are human" and wait until the page shows "Home | Royal Road".
  4. Tap "Continue".
  5. The app process dies and the launcher comes up.
- Logcat (crash buffer): `FATAL EXCEPTION: main`, `java.lang.IllegalStateException: LayoutNode should be attached to an owner`, thrown from Compose `MeasurePassDelegate.remeasure` inside `AndroidComposeView.dispatchDraw`. The trace has no Lume frames above the Compose layer.
- Note: this flow is not in the v1.9.0 change list. I did not build v1.8.0 to check whether it is a regression. Still a crash that users can hit.

**2. "Read in Russian" stays disabled after setup in the same sheet session (minor)**
- Steps to reproduce: open the translation sheet with no AI setup, choose AI (your key), choose a model with "Choose…", enter a key, press Save for the key, then tap the "Read in Russian" switch. The switch does nothing and the hint still says "Set up the AI service below first: a key and a model."
- Closing the sheet and reopening it fixes it (the hint then reads "For this title. Long-press a paragraph to see the original.").

**3. Style note Save hidden behind the keyboard (minor, layout)**
- Steps: in the translation sheet, scroll so the Style note field is at the bottom, tap it and type. The keyboard covers its Save button. Press Back to hide the keyboard before saving.
