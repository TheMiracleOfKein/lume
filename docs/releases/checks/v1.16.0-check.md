# Lume v1.16.0 pre-release check

Build: debug full build of `main` at 1d02d8b (changes since v1.15.1, version still 1.15.1 in `gradle.properties`, so the bump is not in yet). Installed over the previous debug install with `install -r` (the `uninstall` step failed with DELETE_FAILED_INTERNAL_ERROR; the install still replaced the app).
Device: emulator-5554 (`Lume_Light`, 720x1600). Driven with mobile-mcp; adb for launch, force-stop, logcat, and network checks.
Nothing committed, pushed, or changed in source code.

Network note: on this emulator `svc wifi disable` alone left no default route. `svc data enable` (mobile data) brought the route up; after that the site names resolved and the catalog loaded.

## Changed areas
1. Reading progress and brightness shared by both readers (`ReadingRecorder`, `BrightnessWindowEffect`).
2. App preferences split into per-area classes behind the same facade (`AppPreferences`, `ReaderPrefs`, `TrackerPrefs`, `SyncPrefs`, `AiPrefs`).
3. Tracker HTTP calls share a helper (`TrackerHttp`). Only the Trackers dialog could be checked (no accounts).
4. Shared `ConfirmDialog` (replacing about 39 confirm dialogs), shared settings rows.
5. Dead code, unused strings and dependency lines removed.
6. Large files split: `ManageViewModels` into Downloads / Settings / Sources view models, `TitleScreen` (Trackers dialog, "Also on" card, "Similar titles" row), `LibraryDao` into per-area query interfaces.

## Findings

No serious problems found in the app.

1. Minor, not a regression (same as v1.15.1): on the title screen the heart icon ("Remove from library") removes the title immediately, with no confirm dialog. The confirm dialog is used for the Library multi-select Remove, which is where it was checked. Decide whether the title-screen toggle should confirm too.
2. Minor: Trackers, Sources, and the Updates "Failed" lines are shown as expected: MangaBuff "not available in your region", InkStory HTTP 403. These are region blocks, not bugs.
3. Minor, emulator-only: OpenGLRenderer "Unable to match the desired swap behavior" and "force finish cuj, time out: IME_INSETS_ANIMATION" lines appeared in logcat while typing or scrolling. Not fatal; likely emulator GPU (`-gpu host`). Worth a look on a device if it repeats.
4. Tooling note: `uiautomator dump` from adb crashed its own process once (the FATAL above). Not Lume.
