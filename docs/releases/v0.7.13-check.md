# v0.7.13 pre-release device check

Date: 2026-11-03. Build: debug APK `app/build/outputs/apk/debug/app-debug.apk` built from HEAD ef61cd7 (branch feat/chips-and-leftovers) with `./gradlew.bat :app:assembleDebug -q` (succeeded). `adb uninstall` failed with DELETE_FAILED_INTERNAL_ERROR, so the APK was installed with `adb install -r` over the existing install and app data was kept. Device: emulator-5554 (Pixel 6a image, 1080x2400). All driving was done with adb (uiautomator dump for coordinates, screencap for checks). No accounts were signed in and no passwords were typed.

- Catalogue: genre chip first and selected; Popular / Top rated / Completed chips switch the feed.
- Library: filter chips row (Unread, Downloaded, Started, Tracking, Completed) under the category chips; tap cycles off, include, exclude, off.
- Library options: "Filter chips above the titles" and "Continue button on started titles" switches (Display tab).
- Library selection bar: "Bell on or off" button with toast counts.
- Title screen: "Already in the library?" dialog when adding a title whose name matches a library title from another source (Link to it / Add anyway / Open it).
- Sources screen: red "Failed <time>: <message>" line.
- Settings > Library and updates: "Only while charging" (only with automatic check on), "Skip completed titles", "Skip titles you haven't started", "Skip titles with unread chapters"; settings search.
- Update dialog Markdown release notes: not checked (no update dialog triggered).
