# Lume v0.2.0

This release fixes many source problems, makes global search much faster, adds a fullscreen reading mode and adds more settings. Animations now look the same across the whole app.

## Highlights

- **Global search shows results right away.** Each source appears as soon as it answers, so you no longer wait for the slowest site. A slow or blocked source stops after 15 seconds and shows the reason and a **Retry** button.
- **Fullscreen reading.** When you scroll, the reader controls, the status bar and the navigation bar hide. Tap the page to bring them back.
- **Smoother app.** Screen changes, the bottom bar, the side menu, reader controls, lists and loading states all use the same animations.

## Sources

- **Asura Scans:** moved to the new domain (asurascans.com). Scrolling no longer repeats the same 20 titles forever. Popular and Latest now really are different lists. Search uses the site's real search. Paid early-access chapters are hidden until they become free.
- **HiveToons / Vortex Scans:** the full chapter list is shown (before, only the newest ~25 appeared; for example, Lookism has 637 chapters). Popular and Latest are now sorted correctly. The chapter thumbnail no longer shows up as page 1. Locked chapters are hidden.
- **MangaKatana:** titles no longer include "- Update chapter …". Series whose names start with "c" appear again. Descriptions load. Pages load again after a site change.
- **ReManga:** Popular now really shows popular titles. Authors are shown. Titles with special characters in their address no longer crash.
- **MangaDex:** long series show all chapters (they stopped at 500 before). The language filter in search now works.
- **Madara sites:** chapters load on newer versions of the site theme. Opening a title is faster.
- **MangaLib / YaoiLib / HentaiLib:** descriptions, genres and authors are shown.
- Descriptions are shown as clean text, without HTML tags.

## Connection and errors

- Passing a Cloudflare check now also fixes images from that site, and stays valid after you restart the app.
- The Cloudflare check closes by itself when the site has loaded.
- If a site blocks your region or needs a login, Lume tells you so. Before, it showed a Cloudflare check that could never succeed.
- Error messages are now visible on the title, chapter and reader screens. Before, they often just said "No title data".
- Lume retries a request by itself when a site is briefly overloaded.

## Reader

- **Fullscreen while reading** (on by default)
- **Tap zones:** tap the left or right edge to turn the page in page modes; tap the middle to show or hide the controls
- **Volume keys turn pages** (off by default)
- **Keep screen on** (can be turned off)
- **Night dimming**: darkens the pages
- **Side margins in webtoon mode**, for tablets and landscape
- **Read** now starts at chapter 1, not at the newest chapter
- The reader's settings panel scrolls, so every option is reachable on small screens

## Title screen

- **Open in browser** and **Share** buttons

## Settings

The Settings screen is now grouped into General, Reader, Library, Downloads, Search, and Data & accounts. New options:

- How often to check the library for new chapters (3, 6, 12, 24 or 48 hours)
- Check the library only on Wi-Fi
- Download only on Wi-Fi (downloads pause on mobile data and continue on Wi-Fi)
- Show or hide 18+ sources in global search

## Other fixes

- The Back button closes the side menu instead of leaving the screen.
- Search results stay when you open a title and come back.
- The keyboard closes when you start a search.
- Switches and sliders look the same in the reader and in Settings.

## Known issues

- Some sources block certain countries (MangaLib, YaoiLib and HentaiLib, MangaBuff, ReManga's image server). Lume now shows a clear message for this, but cannot get around it.
- Android shows its own "Viewing full screen" notice the first time fullscreen reading starts. This is normal.

## For developers

- New tests: `gradlew :app:testDebugUnitTest` runs the offline unit tests. Add `-Plume.live` to check all built-in sources against the real sites. See [docs/ENGINES.md](../ENGINES.md#live-source-checks).
- New source settings: `rateLimit`, `imageHosts` and `dataSaver` (MangaDex). They are documented in [docs/ENGINES.md](../ENGINES.md).
- Shared animation settings are in `ui/theme/Motion.kt`. Shared settings controls are in `ui/components/SettingsControls.kt`.
