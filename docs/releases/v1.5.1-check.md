## Problems found

1. **AniList search returns "Nothing found" in Ranobe mode.** Repro: Ranobe mode, open any novel (for example RanobeLib "Поднятие уровня в одиночку: Рагнарёк"), Trackers, tap AniList, enter "Omniscient Reader", tap Search. Expected: novel results with "Novel" or "Light novel" plus year. Actual: "Nothing found", for "Omniscient Reader" and "Solo Leveling" alike, and no error text. The same tracker in Manga mode returned results for "Overgeared". Shikimori in Ranobe mode returns novels for the same query, so the problem looks AniList-specific (possibly the format filter for novels or the request). Not yet narrowed down; no network error appears in the app log.
2. **AniList result title shows "null".** Repro: Manga mode, title "Overgeared", Trackers, AniList, Search. The first result's title reads "null" (format line "Manhwa · 2014"). Possibly a null title field from the AniList response that is not handled.
3. **Test-tooling crash noise in logcat.** The FATAL EXCEPTION hits come from the UI dump command run while another UiAutomation session was active (uid 2000). They are not an app crash. Running the adb uiautomator dump while mobile-mcp is connected causes them. Not an app bug, but the literal grep in step C cannot be clean while it is in use.
