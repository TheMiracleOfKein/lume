# Lume Translate 2.0.0

The offline translation add-on for Lume now has releases of its own. It is the same engine and the
same language packs as the add-on that came with Lume 1.7.0 to 1.10.0; only the way it is
published changes.

## Changes

- **Its own version.** The add-on was numbered like Lume (1.7.0 … 1.10.0), so every Lume release
  offered an add-on update even when nothing in it had changed. From now on it has its own version,
  starting at 2.0.0, and a new one comes only when the add-on itself changes.
- **Its own releases.** Lume releases no longer carry `lume-vX.Y.Z-translate.apk`. The add-on is
  published as `lume-translate-vX.Y.Z.apk` on releases tagged `translate-vX.Y.Z`. Lume 1.11.0 and
  later find it there when you tap **Install** or **Update** in the reader's translation sheet.

## Updating

- With Lume 1.11.0 or later, the translation sheet offers this version once; install it over the
  one you have. Downloaded language packs stay.
- Lume 1.10.0 and earlier look for the add-on only on Lume releases. Update Lume first; the
  add-on you already have keeps working until then.
- You can also install the APK from this release by hand. It is signed with the same key as Lume.
