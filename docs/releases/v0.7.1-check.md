# Lume v0.7.1: pre-release check

Branch `feat/subscribed-downloads`, diff `v0.7.0..HEAD` (23 files). Debug APK on emulator-5554, driven with Android-MCP (Snapshot-first) plus adb for install, logcat, screenshots and rotation.

Screenshots were kept locally, not in the repository.

## Changed areas

- **Auto-download mode** (`domain/AutoDownload.kt`, `AppPreferences.autoDownloadMode`): Off / All titles / Subscribed, stored as an int ordinal. Legacy on/off bool is the fallback.
- **Per-title subscription** (`title_prefs.autoDownload`, `MIGRATION_9_10`): bell icon on title details, visible only when the title is in the library and mode is not ALL.
- **Library check** (`LibraryUpdateWorker`): queues new chapters per the mode and the per-title flag.
- **Settings → Downloads**: three chips plus hint text.
- **Backup/sync DTOs**: `TitlePrefsDto.autoDownload` added in `BackupRepository` and `SyncRepository`.
- **Sync** (`SyncRepository.backendFor`): `Uri.parse` replaced by `toUri()` with `requireNotNull` on the folder.
- **EN and RU strings** for the above.

## Failed or inconclusive

1. **Reader page area is black** (MINOR, unverified). Chapter 1 Prologue from Asura Scans shows the header, slider and controls, but the page image area stayed black after 14 s. Per the release notes this can be an Asura early-access or source issue. It was not compared against another source (MangaKatana), so it is not counted as a Lume regression.
2. **Sync → Sync now with mode Off** (MINOR, not reproduced as stated). Tapping "Sync now" changed nothing: status stayed "Not synced yet", and no "No sync folder chosen" text appeared. No crash. This is expected: `SyncRepository.sync()` does nothing when sync is off. The Folder chip was not selected because it opens the system folder picker, so the no-folder state under Folder mode is unverified. Repro: Settings → Sync → Sync now.

## Read from code, not run

- `SyncRepository.backendFor` uses `requireNotNull(settings.folder) { "No sync folder chosen" }`. Its only caller, `runSync`, runs inside `sync()`, which catches the exception and puts its message in the sync status, so a Folder-mode sync with no folder shows "No sync folder chosen" instead of crashing.
- Enabling a subscription while mode is Off silently switches mode to Subscribed (`TitleViewModels.toggleSubscribed`). Intended, but a user who never opened Settings will not see it change.

## Tooling notes

- One adb `uiautomator dump` run while the Android-MCP session was active produced a `FATAL EXCEPTION` in the uiautomator process itself (PID 11382, `UiAutomationService already registered`). It is not in com.lume.app. Avoid running `uiautomator dump` while Android-MCP is connected.
