## Changed areas (`git diff --stat v0.9.2..HEAD`, 20 files, 1001 insertions)

- New engine: `InkStoryEngine` (catalogue, search, filters, title details, chapter list with teams, pages), `InkStoryHydration` (parses the `$R[n]` script on the site pages), `SourceEngines` (registration, name, Russian group), `assets/sources/inkstory.json`.
- Network: `ImageDecrypt.kt` (`ImageDecryptInterceptor`, XOR unmasking when a page URL carries the `lume_xor` key) added as the first application interceptor of the shared `AppHttp` client, so reader, downloads, covers and every other source go through it.
- Manifest: `inkstory.net` added to the link-handling host list.
- Strings: two new strings in EN and RU.
- Tests (JVM, not run here): `ImageDecryptTest`, `InkStoryParsingTest`, `LiveSourcesTest` change.

## Possible bug spots (from reading the code)

1. The decrypt interceptor runs on every image request. It only acts on URLs that carry `lume_xor`, so other sources should pass through unchanged. Checked on device with MangaKatana (below).
2. Browse has no sort chips for InkStory (`browseSections()` is not overridden). Latest is reachable only through Search > Filters > Sort.
3. Team chips in the chapter list appear only for titles with several translation teams. Not reached on device.
4. Restricted titles (`readingRestriction` other than NONE) are left out of lists and fail with a message when opened directly. Not reached on device.

## Findings

### Serious

None found. No crash, broken navigation, data loss or layout break reproduced in the steps above.

### Minor

- M1. Browse catalogue for InkStory has no sort chips (Popular / Latest). Only the popular list is shown in Browse; Latest needs Search > Filters > Sort > "Latest updates". Repro: Menu > Source > InkStory, then Catalog. Compare with sources that define sections (for example MangaKatana-style chips on other sources). Decide whether this is intended.
- M2. Catalogue entry "Расстройства Джеффа" shows only "88" under the title (no type label such as "Manhwa · 88"). Repro: InkStory Popular, scroll to page 2. Probably missing type metadata on the site.
- M3. Chapter rows show no team name for single-team titles, and the team chips are hidden then. Expected by design; team selection was not exercised.
