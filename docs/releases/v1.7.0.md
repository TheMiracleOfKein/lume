# Lume v1.7.0

Chapter translation: read English novels in Russian, and Russian ones in English.

## New

- **Translate chapters.** The text reader's top bar has a translate button. **Read in Russian** (or **Read in English** for RanobeLib) is saved for each title. The chapter changes language starting from the paragraph you're on, and the top bar shows how far it has got. Translated chapters are kept for a while, so going back is instant.
- **Three ways to translate**, picked in the translate sheet:
  - **Google Translate**: online, free, nothing to set up. The chapter text goes to Google.
  - **DeepL**: online, with your own key from a free DeepL API account (500,000 characters a month). The key is stored encrypted on the phone and is never part of backups or sync.
  - **On the phone**: offline and private, with the open-source models Firefox uses (English → Russian for now). It needs the free **Lume Translate** add-on (about 7 MB), installed from the sheet. Its language pack (about 24 MB) downloads from Mozilla when you ask. No Google services needed, and no chapter text leaves the phone.
- **Original on a long press.** Long-press a paragraph to see the original text, in scroll and page mode. It can be copied, and a name from it added to the glossary.
- **Glossary.** Names and terms that must read the same in every chapter of a title ("Shirou = Широ", "mana core = ядро маны"), with every engine.
  - Its own screen: search, sort by name or newest, add, edit and delete terms, paste a whole list at once, and copy all terms to share them.
  - It fixes the spelling; word endings stay as the translation has them.
  - It is part of backups and sync.
- **Read aloud** goes on in the translation, also in the chapters after the one you're reading.

## Lume Translate

A separate small app from the same release (`lume-v1.7.0-translate.apk`), only needed for translating on the phone. Only Lume can use it. Its icon opens a page with the downloaded language packs and a button back to Lume. It runs on 64-bit phones (and x86_64 emulators and Chromebooks).

## Updating

Install it over v1.6.0 as usual. Your library, progress, bookmarks, downloads, sign-ins and tracker links are kept. The database gets a new table for glossaries and a translation setting per title (an additive change, tested). Backups now use format version 6 with the glossaries; older backups still load.

## Privacy

Online translation sends the text of the chapters you translate to Google or DeepL, and only after you pick that service. Translating on the phone sends nothing; the add-on only downloads the language pack from Mozilla's model storage when you tap download. See [PRIVACY.md](../../PRIVACY.md).

## For developers

- New `:core:translate` (AIDL `ILumeTranslator`, the signature permission `com.lume.permission.TRANSLATE`, and `ModelCatalog` with pinned Firefox Translations model paths, sizes and SHA-256 hashes) and a new app module `:translate-addon` (`com.lume.translate`).
- The add-on builds bergamot-translator (MPL-2.0, git submodule under `translate-addon/third_party`, two small patches in `translate-addon/patches`) with the NDK for `arm64-v8a` and `x86_64`. Clone with `git submodule update --init --recursive`; without the submodule the rest of the project still builds.
- `TranslationProvider` is the seam for engines (`AddonProvider`, `GoogleProvider`, `DeepLProvider`); an LLM API can be one more. Text travels as HTML: `<b>`/`<i>` and glossary marks `<span data-g="N">` are moved onto the translated words by the engine, then replaced by the glossary target (`TranslationMarkup`).
- Translation is block for block (same count), so positions, progress and read aloud work unchanged. The cache keeps engine output per chapter, provider, languages and glossary terms.
- Room 17 → 18 (`title_prefs.novelTranslateTo`, `glossary_terms`), backup format 6, sync key group `glossary_terms`.
- `AppUpdater` takes the installed version, preferences and download folder, and installs the add-on from the `translate` release asset. CI and the release workflow check out submodules and build, check and publish the fourth APK.
