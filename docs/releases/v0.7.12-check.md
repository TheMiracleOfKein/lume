Date: 2026-11-01. Build: debug APK `app/build/outputs/apk/debug/app-debug.apk` installed on the emulator with `adb install -r` over the existing install (`adb uninstall` failed with DELETE_FAILED_INTERNAL_ERROR, so app data was kept). `aapt2 dump badging` reports versionName 0.7.11, versionCode 24: the version bump is still a release step, so the version shown in About is 0.7.11 (24). ## Failed

1. Updates check while offline: no failure is shown (medium, UX and release-note mismatch). RESOLVED in the re-check (see "Re-check after fix").
   - Steps: Updates > Update now with airplane mode on (`cmd connectivity airplane-mode enable`).
   - Observed: the button is disabled and a spinner runs in the header area; no "Last check failed" or failure count appeared. The worker (`LibraryUpdateWorker`) was cancelled by the network constraint ("Constraints not met") and only ran after airplane mode was turned off (19:39:03, result SUCCESS at 19:39:08). After reconnect the header still read "Checked 0 minutes ago" with no failure note.
   - Expected (v0.7.12 notes): "Updates shows 'Last check failed' when no title could be checked (for example without internet)".
   - So the offline failure path was not observed. The check waits on the network constraint and never fails while offline. Worth deciding whether the spinner should end with a failure note when offline.

2. Sync "Sync now" with mode Off: message not confirmed (severity: low, needs a look by a person).
   - Steps: Settings > Sync (mode Off) > Sync now.
   - Observed: a grey bar at the bottom of the screen for a few seconds, no readable text in the screenshot or in the element list. "Sync is off. Choose a sync mode first." was not seen.
   - Possible causes: snackbar text colour or a timing issue. Check on a device.
