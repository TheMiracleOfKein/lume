# Lume v0.9.3

A new Russian source: InkStory.

## New

- **InkStory** (inkstory.net). Manga, manhwa and manhua in Russian: popular and latest lists, search, sorting, and genre and tag filters. Chapters from every translation team are listed, so you can pick a team in the chapter list as with MangaLib.
- **Only what you can read.** Titles that the site shows only to signed-in users, library members or premium accounts are left out of the lists, and paid chapters are skipped. If you open such a title from a link, Lume says that it's restricted instead of showing an empty chapter list.

## Known issues

- InkStory's Browse screen shows only the popular list. For the latest chapters, use Search → Filters → Sort.
- Chapter pages on InkStory are large (several MB each), so reading uses more data than on other sources.

## Not added

- **Com-X.life** stays out. The site checks every visitor with its own browser test, which Lume can't recognise or pass, so the source wouldn't work reliably.

## Updating

Install it over v0.9.2 as usual. Your library, progress, bookmarks and downloads are kept. The database doesn't change.

## For developers

- `data/source/InkStoryEngine.kt`: the site has no public JSON API, so the engine reads the data the server renders into each page (a JS expression, not JSON). `InkStoryHydration` turns it into a JSON tree, and the engine finds objects by field name, not by position, so a redeploy is less likely to break it.
- Page images are served scrambled with a key that the chapter page provides. `data/network/ImageDecrypt.kt` has an `ImageDecryptInterceptor` on the shared client that unscrambles tagged image URLs and passes every other image through unchanged.
- Manifest `assets/sources/inkstory.json`, with a rate limit of 1 request per second.
- New tests: `InkStoryParsingTest` (lists, details, chapters, restricted and paid chapters, pages, the page-data reader) with saved pages in `fixtures/inkstory`, and `ImageDecryptTest`. `LiveSourcesTest` covers InkStory.
- Device check: [v0.9.3-check.md](v0.9.3-check.md).
