# v0.7.11 pre-release device check

Build: gate APK (`lume-gate.apk`) installed on emulator-5554 (Pixel 6a, 1080x2400, Android 17 image) with `adb install -r` over the existing install. `aapt2 dump badging` reports versionName 0.7.10, versionCode 23. The working tree's `app/build.gradle.kts` says 0.7.11 (24), but that change is uncommitted and the APK predates it, so the version check below is for the build under test, not the final v0.7.11 artifact. `adb uninstall` failed with DELETE_FAILED_INTERNAL_ERROR; `install -r` succeeded.

Tools: mobile-mcp for UI driving (element list first; screenshots for pixels). adb for install, logcat, airplane mode, rotation settings and screen captures. Note: mobile-mcp reports the device as `Pixel_6a`, not `emulator-5554`, so all mobile-mcp calls used that id.

## Changed areas checked

- Back button on top bars (labels checked in element lists).
- Main menu items (launchSingleTop behaviour).
- Reader: prev/next chapter at the newest chapter, middle chapter next button.
- Reader: loading/error state with top bar Back.
- Reader: paged zoom: NOT CHECKED.
- Reader: tall webtoon pages (Asura): partially checked on a current chapter (not an old one).
- Rotation (landscape reader).
