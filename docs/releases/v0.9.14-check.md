## Failed / problems

**SERIOUS: none.**

**Minor**

- **M1. Keyboard stays open after submitting the catalog search.** Steps: Catalog > "Search in this source" > type `hero` > Enter. The keyboard stays visible with the field focused, although the submit handler calls `keyboard.hide()` and `clearFocus()`. The library search, which uses the same `QuickSearchBar`, shows the same behaviour. Consequence: the first Back only closes the keyboard, and a second Back clears the search. It may be specific to the emulator's input method; check on a device before deciding.
- **M2. Apply with text in the search field runs a text-only search.** The sheet's note explains that this site ignores filters when there is search text. Apply still runs the search and returns results without the genre applied. This is by design, but the user may read the result list as filtered. Option: disable Apply while the field has text, or show the note near Apply too.
- **M3. Import order in `FilterPanel.kt` and `CatalogScreen.kt`.** New imports were inserted in the middle of the existing import block. Cosmetic only.
