# Lume v0.6.3

Reading lists: share what you read with a friend as a small file, and add a list someone shared with you to your library in one tap.

## Highlights

- **Share a reading list.** Tap the share button at the top of the **Library**. The list holds the titles you see: the whole library, the open category, or only the titles you selected first (the share button is in the selection bar too). Give it a name, then share it through any app or save it as a file.
- **What a list holds.** Each title's name, cover, source and web link. Your progress, read marks, bookmarks and sign-ins are never in it.
- **Open a reading list.** Open the file in Lume: share it to Lume, tap it in a file manager, or pick it under **Settings → Backup and restore → Open a reading list**. Lume shows every title in the list:
  - titles already in your library are marked;
  - a title from a source you don't have is looked up by its web link on your other sources;
  - the rest are ticked; untick what you don't want, pick a category if you like, and tap **Add**.

## Fixes

- A website link or file shared to Lume while Lume was already open sometimes went to a Lume window in the background, so nothing seemed to happen. It now opens in the window you are looking at.

## Updating

Install it over v0.6.2 as usual. Your library, progress, bookmarks and downloads are kept. The database doesn't change.

## Known limits

- Titles added from a list show their chapter count after the next library check (or after you open them).
- Lists longer than ten titles skip tracker linking and the "Also on …" search for the added titles, so dozens of searches don't start at once. "Find on other sources" on the title screen still works.

## For developers

- The format is `lume-reading-list` version 1 (`domain/ReadingList.kt`): JSON with `name`, `createdAt` and `titles` (`sourceId`, `titleId`, `title`, `coverUrl`, `typeLabel`, `url`, `sourceName`). Unknown fields are ignored, so later versions stay readable. Parsing, the import plan and file names are unit-tested.
- `data/library/ReadingLists.kt` builds, writes and opens lists; `ReadingListScreen` shows one. Shared files go through a `FileProvider` (`res/xml/shared_files.xml`, `cache/shared/`).
- `MainActivity` takes `application/json` from `SEND` and `VIEW`. `AppShell` only takes a route while its window is resumed.
- `LibraryScreen.kt` is split into `LibraryScreen`, `LibraryItems` (grid, list, badges) and `LibrarySheets` (options sheet and dialogs). No behaviour change.
