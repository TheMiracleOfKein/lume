# Lume v1.16.0

A cleanup release. Nothing new to see: the app works as before, with less duplicated code underneath, so the next features are easier to build and test.

## Changed under the hood

- **Both readers share one reading session.** The manga and novel readers now save progress and history, and apply the reader's own brightness, through the same code, so a fix in one reaches both.
- **Settings are stored by area.** The one large settings store is split into appearance, reader, AI, sync and tracker parts behind the same interface. Your saved settings stay as they are.
- **Trackers share one request helper** for sign-in tokens, errors and retries.
- **One confirm dialog.** About 40 "Are you sure?" dialogs now use the same component, and duplicate settings rows (sliders, switches) were merged.
- **Dead code removed:** unused strings, functions and dependency lines are gone, and the largest files (settings, downloads and sources screens, the title screen, the library database queries) are split into smaller ones.

## Details

- No database change and no new permissions. Backups and sync files are the same as in v1.15.1.
- The Lume Translate add-on is unchanged.
