# Lume v0.7.2

Bring your MangaLib bookmarks into the library in one tap.

## Highlights

- **Import bookmarks from MangaLib, HentaiLib and YaoiLib.** Sign in to the source (Sources → the sign-in button on its row), then ⋮ → **Import bookmarks**.
- **Folders become categories.** "Читаю", "В планах", "Прочитано", your own folders: each turns into a Lume category of the same name, or joins an existing category with that name. Empty folders are skipped.
- **Nothing is lost.** Titles already in the library stay where they are and gain the folder's category. A title in several folders gets all of them.
- Covers and types come along, so the library looks right before you open anything. The next library check loads the chapters.
- A spinner on the source row shows the import is running; a message says how many titles were added, how many were already there, and how many folders became categories.

## Updating

Install it over v0.7.1 as usual. Your library, progress, bookmarks and downloads are kept. No database changes.

## Known limits

- Read progress on the site (the last chapter read) isn't brought over yet; only the titles and folders are.
- Titles bookmarked on another Lib site are left out: import them from that site's source (for example HentaiLib titles from the HentaiLib source).
- The import needs a sign-in. A site that blocks your region blocks the import too.

## For developers

- `data/source/LibBookmarks.kt`: `parseLibBookmarkFolders` (`/bookmarks/folder/{userId}`) and `parseLibBookmarksPage` (`/bookmarks?user_id=…&status=…&page=…`). The title is read from `media` or the top level; paging follows `meta.has_next_page`, `links.next` or `current_page`/`last_page`; an empty page always stops. Entries whose `site` differs from the source's `siteId` are skipped.
- `LibSocialEngine.fetchBookmarks()`: user id from the stored `LibAuthToken`, folder by folder (all bookmarks in one pass when the site gives no folders), at most 200 pages per folder.
- `data/library/LibBookmarkImport.kt`: `planLibBookmarkImport` groups folders per title and drops empty folders; the import writes categories and bookmarks in one transaction, like the Mihon import. Wired as `AppContainer.libBookmarkImport`.
- `SourcesViewModel.importBookmarks` and a new menu item in `SourceRow`. JVM tests in `LibBookmarksTest`.
