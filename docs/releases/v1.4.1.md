# Lume v1.4.1

A fix for the two English novel sources added in v1.4.0.

## Fixed

- **Royal Road** and **Scribble Hub** chapters open in the text reader again. In v1.4.0 every chapter from these two sites showed only "z73" instead of the text.

## Updating

Install it over v1.4.0 as usual. Your library, progress, bookmarks, downloads and sign-ins are kept. No database change.

## For developers

- `NovelHtml`'s rule for classes a page hides (`display: none`) had a bare `}` in its regex. The JVM accepts that, but Android's ICU regex engine rejects it, so the object failed to initialise on devices. Every chapter of both sources then failed, and the reader showed the exception, whose only text was the R8-shortened class name. All braces in the pattern are escaped now. The JVM parser tests couldn't catch this, so the fix was checked on the emulator.
