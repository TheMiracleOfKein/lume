# Lume v0.9.6

Reading statistics, a notification per title, updates for chosen categories, and source errors that stay visible.

## New

- **Reading statistics.** A new screen shows how many chapters and pages you've read and how long you've spent reading, overall, for each of the last 12 months, and for each title. Open it from the icon in the History top bar or from Settings → Library. Reading time stops counting after two minutes on the same page, and nothing is recorded in incognito mode. The numbers stay on the phone. They're included in the JSON backup but not synced between devices.
- **One notification per title.** New chapters are now announced in a separate notification for each title, grouped under one summary. Tapping a notification opens that title. The next update check replaces a title's notification instead of adding another one.
- **Notify for categories.** In Settings → Library, choose which categories notify you about new chapters. A title in several categories stays quiet only if all of its categories are turned off.
- **Update categories.** In Settings → Library, choose which categories the update check covers. It still checks the titles with the bell (or your 20 most recently read titles) and now skips the ones outside the chosen categories. With nothing chosen, every category is checked. "Update now" follows the same choice.
- **Source errors are remembered.** The last error of a source on the Sources screen now survives an app restart for up to a week. Global search shows the same error under a source that is still loading or found nothing. The error is cleared as soon as the source works again. It is stored only on the phone and isn't included in backups.

## Updating

Install it over v0.9.5 as usual. Your library, progress, bookmarks and downloads are kept. The database moves from version 13 to 14 (a new reading-sessions table), and backups made by this version use format 5. Older backups still restore.

## For developers

- Notifications: `domain/UpdateNotifications.kt` (`notifiable`, uncategorized as id `0`). `LibraryUpdateWorker` posts children tagged `title:<source>/<title>` with a group summary (id 42). The muted set is in `library_notify_muted_categories`.
- Category filter: `UpdateRules.categories` and `inCategories()`, stored in `library_update_categories`. Deleting a category removes it from both sets. The shared picker is `settings/CategoryPickDialog.kt`.
- Source status: `SourceHealth` takes a `SourceHealthStore`. `PrefsSourceHealthStore` keeps the map in the private DataStore (`source_problems`) and drops entries older than 7 days on load. `ui/components/SourceProblemLine.kt` is shared by the Sources screen and global search.
- Statistics: `ReadingSessionEntity` (`reading_sessions`) and `MIGRATION_13_14`. `ReadingSessionTracker` is fed from `ReaderViewModel` and enforces a 2-minute idle cap and a 5 s / one-page minimum. `ReadingStats` does the aggregation and `StatsScreen` / `Routes.Stats` show it. `BackupPayload` is now version 5, with `readingSessions`; restore merges sessions and skips duplicates.
- Device check: [v0.9.6-check.md](v0.9.6-check.md).
