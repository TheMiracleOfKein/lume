## Failures

### F1. Bookmark delete: Undo snackbar hidden behind the bookmarks sheet (item 5)
- Severity: minor. The delete itself works. The Undo it offers can't be seen or used while the sheet is open, and it does not show after the sheet closes.
- Repro:
  1. Open any chapter in the reader.
  2. Tap the bookmark icon (bottom bar, centre) to add a page bookmark.
  3. Long-press the same icon to open the Bookmarks sheet.
  4. Tap the trash icon on the bookmark row.
  5. The sheet stays open. A grey strip peeks out above the sheet edge; no "Undo" text is visible (v0715-09-bookmark-delete-undo-check.png).
  6. Close the sheet (tap above it). No Undo is visible (v0715-10-after-close-snackbar.png).
- Expected: the Undo snackbar is visible above the sheet, or the Undo stays reachable after the sheet closes.

### F2. Bookmarks sheet header differs from the Settings sheet (item 5)
- Severity: minor (visual consistency). The two sheets were meant to share a header.
- Repro: reader → Tune icon: the sheet has "Settings" with a Close (×) button (v0715-28). Long-press the bookmark icon: the sheet has "Bookmarks" with no Close button (v0715-06).

### F3. Library empty-state and tab wording (item 6, item 14)
- Severity: minor (copy). Not verified against the string catalogue.
- Repro: with an empty library, the Library tab shows "No bookmarks" in English (v0715-02). In Russian the tab reads "Закладки" (bookmarks) (v0715-35).
- Expected: wording that matches the Library, or confirmation that this is intended.

### F4. Raw parser error shown as a search result (item 8)
- Severity: minor. The source is blocked for that query, but the user sees technical text.
- Repro: Home → Quick search → type "Solo Leveling" → Enter. The MangaDex card shows "Unexpected JSON token at offset 11: Expected EOF after parsing, but had h instead at path: $ JSON input: <!doctype html>…".
- Expected: a short, translated error message, for example "Source unavailable".
