# Lume v1.5.6

A guided view fix.

## Fixed

- **Pages no longer open zoomed into an old panel.** With guided panel view on, a page you came back to could still show the panel you had last zoomed into, for example after going back a page or jumping with the page slider. Every page you arrive on now shows whole, and the next tap starts from its first panel.

## Updating

Install it over v1.5.5 as usual. Your library, progress, bookmarks, downloads, sign-ins and tracker links are kept. No database change.

## For developers

- Telephoto's zoom state outlives the guided step (it is saved with the page), so `PagedReader` now also resets the zoom of the page that settles when it has no panel step, not only of the page that was left.
