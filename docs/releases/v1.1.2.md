# Lume v1.1.2

Two fixes for MangaLib and the other Lib sites (HentaiLib, YaoiLib).

## Fixed

- **Paid chapters are no longer listed.** Chapters in paid early access, which can't be read yet, are left out of the chapter list and out of Updates. A chapter shows up as new once it opens for everyone. If a chapter has a free translation next to a paid one, only the free one is listed.
- **Green stripes over pages.** Some newer MangaLib chapters (for example the latest One Punch-Man) are stored as 12-bit AVIF images, which Android draws covered in green stripes. Lume now notices this on the first page and loads that chapter from the site's mirror, which serves the same pages as JPEG. Other chapters still load from the main server.

## Updating

Install it over v1.1.1 as usual. Your library, progress, settings and sign-ins are kept. No database change. Paid chapters that were already in your library's chapter list go away at the next update check.

## For developers

- `LibSocialEngine.parseChapters` skips branches whose `restricted_view.is_open` is false, and chapters with no open branch.
- The image server check reads the first kilobyte of the first page (`imageHead`) instead of one byte. `ImageBytes.isUnsupportedAvif` reads the `av1C` box: anything but the AV1 Main profile (8/10-bit 4:2:0) moves that chapter to the next server. JVM tests cover both.
- The device check is in [v1.1.2-check.md](v1.1.2-check.md).
