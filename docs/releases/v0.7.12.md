# Lume v0.7.12

Polish: a tidier menu, a library grid that fits big screens, dialogs that survive rotation, clearer update checks, safer sync, and downloaded pages in the right order.

## New

- **Search from Home.** The search bar on Home is now a real text field: type and press enter, and the search across all sources opens with your words already in it.
- **Clear History.** History has a clear-all button in the top bar, with a confirmation.
- **A shorter main menu.** It no longer repeats Home, Library, Catalog and Updates from the bottom bar. It keeps Search, Sources, Settings, Downloads, History and About, plus the theme and incognito switches.
- **The library grid fits the screen.** Covers keep a steady size, so tablets and landscape show more columns instead of huge covers. Settings and the title details stay a readable width on wide screens.

## Fixed

- **Rotating the phone keeps open dialogs** and what you typed in them: categories, trackers, sources, filters, sign-in forms and confirmations.
- **The library check tells you when it fails.** Updates shows "Last check failed" when no title could be checked (for example without internet), or how many titles failed. A check that fails completely is retried later.
- **Downloaded and local chapters show pages in order.** Pages named 1, 2 … 10 were read as 1, 10, 2; numbers are now compared as numbers.
- **The same chapter can't be queued twice for download.**
- **Unpacked CBZ chapters use at most 300 MB** of cache; the oldest are removed first.
- **Sync:**
  - A phone whose clock is behind no longer loses its changes.
  - A title removed on one phone no longer comes back from a phone that was offline for more than six months.
  - Sync files are written in full before they replace the old ones, so another phone never reads a half-written file.
  - "Sync now" with sync turned off says so instead of doing nothing.
- **Lib bookmark folders** get their names in the app's language (Reading, Planned, Dropped, Read, Favourites).

## Updating

Install it over v0.7.11 as usual. Your library, progress, bookmarks and downloads are kept. The database moves to version 11: duplicate entries in the download queue, if any, are removed. Chapters you unpacked from CBZ files are unpacked again the first time you open them.

## For developers

- `MIGRATION_10_11`: drops duplicate `(sourceId, titleId, chapterId)` rows in the download queue (keeps the lowest id), then adds a unique index. `insertDownloadQueueIgnore` uses `IGNORE`.
- `LibraryUpdateWorker` counts checked and failed titles (`domain/LibraryCheck`), rethrows cancellation, returns `retry()` when every title failed (up to 3 attempts); `AppPreferences.setLibraryLastCheck` stores the time and outcome.
- `domain/NaturalOrder` for page, chapter and series order in `LocalEngine`, `DownloadStore` and `LocalImporter`; cache folders renamed (`cbz/n…`, `local_zip/n_…`) so old lexical caches aren't reused.
- `data/ArchiveCache` with `domain/CacheTrim.selectCacheTrim` caps the unpacked archive cache at 300 MB.
- `data/title/LruMap` (200 entries) for `TitleRepository`'s memory caches.
- `SyncMerge.stampTime` (monotonic stamps), tombstones kept 3650 days; folder and WebDAV backends write to `.tmp` and then rename or `MOVE`. PBKDF2 stays at 120,000 iterations: raising it needs a new file format that older versions can't read.
- `rememberSaveable` for dialog flags and typed text in Categories, Chapters, Library, Sources, Title, Tracker settings, Search and Home.
- Library grid uses `GridCells.Adaptive(116.dp)` (88 dp compact); `SettingsScaffold` and the title details are capped at 840 dp.
- New tests: `NaturalOrderTest`, `CacheTrimTest`, `LruMapTest`, `LibraryCheckTest`, sync stamp and tombstone tests, `MigrationTest` 10 → 11.
