# Lume v1.12.1

A fix for the Lib sites. MangaLib, RanobeLib, HentaiLib, SlashLib and YaoiLib stopped loading for some readers: the app asked the old API address (`api.cdnlibs.org`), which no longer answers there.

## Fixes

- **Lib sites load again.** All of them now use the address the sites themselves use (`api.lib.social`). Catalogs, search, chapters, sign-in and bookmark import go through it.
