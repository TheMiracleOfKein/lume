# Lume v1.15.1

A fix for the reader's own brightness.

## Fixed

- **Brightness now steps the way the eye sees it**, like the phone's own slider. Before, 1% was noticeably brighter than the phone's lowest setting, and above about 50–60% the screen barely changed. Now 1% is the screen's minimum and every step up to 100% is visible.
- Applies to the left-edge brightness swipe in the novel reader and to the **Brightness** slider in the manga reader.

## Details

- A level you set before stays the same number, so the screen may look dimmer at the same percentage than in v1.15.0. Set it once more to taste.
- When the swipe starts from the system brightness, the level shown now matches the phone's slider more closely.
