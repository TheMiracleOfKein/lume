# Lume v0.7.5

Bookmark import shows where it is and keeps going when you leave the screen. Lume can now update itself from GitHub.

## New

- **Import progress.** Import bookmarks opens a card at the top of Sources with the step it's on (loading bookmarks, adding titles, read progress) and a progress bar. The read-progress step counts titles: "12 of 140".
- **The import outlives the screen.** Leave Sources and come back: the card is still there with the current step. When it's done, the card shows the summary until you close it.
- **Updates from GitHub.** Lume checks the latest GitHub release on start (at most every 6 hours). When there's a newer version, a dialog shows the release notes with **Download and install**, **Later** and **Skip**. The APK downloads with a progress bar, then Android asks you to confirm the install.
- **About → Updates.** The installed version, a **Check for updates** button and a switch for the automatic check.

## Updating

Install it over v0.7.4 as usual. Your library, progress, bookmarks and downloads are kept. No database changes.

The first update from inside Lume asks you to allow installs from Lume (Android's "Install unknown apps" setting). Allow it, come back and tap Install again.

## Known limits

- The import runs while Lume's process lives. If Android closes Lume in the background during a long import, start it again: it doesn't make duplicates.
- Release notes in the update dialog are shown as plain text.
- Pre-releases and drafts are never offered.

## For developers

- `LibBookmarkImport` takes the app scope, runs the import there (`start`, `dismiss`) and exposes `status: StateFlow<LibImportStatus?>` with `LibImportStage` (`Fetching`, `Adding`, `Progress(done, total)`, `Finished`). `SourcesViewModel` only reads it.
- New `data/update/AppUpdater` (`AppContainer.updates`): `releases/latest` from the GitHub API, `isNewer` and `parseRelease` (JVM tests in `AppUpdaterTest`), download to `cache/shared/update/` (served by the existing FileProvider), install through `ACTION_VIEW`. New permission `REQUEST_INSTALL_PACKAGES`.
- `UpdatePrompt` sits in `LumeRoot`; `UpdateSection` in About.
