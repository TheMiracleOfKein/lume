# Lume v1.5.3

Swipe between tabs, pick the translation while reading, and SlashLib.

## New

- **Swipe between tabs.** In the Catalog, swipe left or right to move between Popular, Updates and Library; in Search, between Current source and All sources; in the Library, between your categories ("All" first). Tapping a tab still works. A swipe on a row of chips scrolls the chips; while titles are being picked in the Library, swiping is off.
- **Switch the translation while reading.** When a chapter on MangaLib or RanobeLib has several translation teams, the reader shows the team's name under the chapter name. Tap it to pick another team's translation of the same chapter. The next and previous chapters then follow that team, and it becomes the title's preferred team. The manga reader stays on the same page; the text reader starts the chapter from the top, because the translations don't line up.
- **SlashLib** joins the manga sources (adult content, next to YaoiLib). Its links open in Lume.

## Changed

- **Continue reading:** a tap on a card's cover opens the title page; a tap on its name or chapter goes on reading, as before. The same goes for the cover in History.
- **The text reader's title opens the title page**, as it already did in the manga reader.

## Fixed

- **RanobeLib title pages show the description again**, and so do MangaLib titles that had none. The site now sends descriptions as rich text, which Lume didn't read.

## Updating

Install it over v1.5.2 as usual. Your library, progress, bookmarks, downloads, sign-ins and tracker links are kept. No database change.

## For developers

- `SwipeTabPager` (`core/ui`) puts a `HorizontalPager` under an existing tab row; the tab state stays the source of truth (a tap animates the pager, a settled swipe reports back).
- `chapterTranslations(all, chapter)` (`core/model`, `ChapterDedupe.kt`) lists every team's copy of a chapter; both readers use it with a shared `TranslationPickerSheet` (`core/ui`).
- `LibSocialBase` reads `summary` as an HTML string or a rich-text document (through `LibChapterText`), falling back to `description` and `rawSummary`.
- New manifest `slashlib.json` (`libsocial`, site id 2).
