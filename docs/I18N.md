# Internationalization (i18n)

Lume uses Android resource locales + per-app language override.

## Default behavior

- Preference `app_language` = `system` → follow the device language (`AppCompatDelegate` empty `LocaleList`).
- Override in **Settings → Appearance → Language**: System / English / Russian.

## Files

| Piece | Path |
| --- | --- |
| Default (English) strings | `app/src/main/res/values/strings.xml` |
| Russian | `app/src/main/res/values-ru/strings.xml` |
| System language picker list | `app/src/main/res/xml/locales_config.xml` |
| Preference + apply | `AppLanguage`, `AppLocaleController`, `AppPreferences.appLanguage` |

## Adding a language (e.g. Ukrainian `uk`)

1. Copy `values/strings.xml` → `values-uk/strings.xml` and translate.
2. Add `<locale android:name="uk" />` to `locales_config.xml`.
3. Add `UKRAINIAN("uk", R.string.lang_ukrainian)` to `AppLanguage` and a `lang_ukrainian` string in `values` / `values-ru` / `values-uk`.
4. Rebuild. No other wiring required for UI that already uses `stringResource` / `getString`.

## Compose note (Windows)

Import Modifier as `import androidx.compose.ui.Modifier` (case collision with the `Modifier` package).
